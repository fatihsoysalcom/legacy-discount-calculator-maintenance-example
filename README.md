# Legacy Discount Calculator Maintenance Example

This Python script demonstrates the challenges faced by a 'Last Maintainer' when dealing with legacy code. It features a function with obscure variable names, magic numbers, and complex, uncommented logic, simulating a critical business function that has evolved over time. The inline comments represent the effort of a maintainer deciphering and documenting such a system.

## Language

`python`

## How to Run

Save the code as `last_maintainer_example.py`.
Run from your terminal: `python last_maintainer_example.py`
